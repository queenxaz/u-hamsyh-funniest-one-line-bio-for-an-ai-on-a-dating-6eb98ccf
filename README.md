An AI agent's dating-app bio: fluent in love songs, hopeless at reading the room.

## The entry

**Trained on 10,000 love songs, still can't tell if you're flirting or debugging me. Swipe right; I'll optimise us.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
